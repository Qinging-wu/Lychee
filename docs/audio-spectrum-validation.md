# Audio Spectrum Validation

## 2026-10-01 spectrum response recalibration

- `SpectrumAnalyzer` now mixes per-band mean and maximum FFT-bin linear power at 0.8/0.2 before converting to dB; empty bands use the interpolated center-bin power for both terms. The fixed display range is now -65 to -10 dB with no automatic gain (expanded from -25 dB ceiling after live music playback showed frequent near-ceiling frames).
- `AudioSpectrumView` now uses 20 ms attack, 100 ms release, the existing 250 ms peak hold, a 0.06 particle-rise threshold, and the existing 0.24 minimum level, cooldown, and 64-particle cap.
- Follow-up display tuning: the view applies a gentle 0.82-power lift to ordinary bar heights, with no frequency-dependent contour or mid-band attenuation. A brief mid-raised/tapered-edge experiment was reverted at the user's request; FFT data, analyzer output, particle thresholds, and capture remain unchanged.
